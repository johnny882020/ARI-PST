# CMS path restriction (RT-10)

Editors (Decap CMS at `/admin`) may change **only** `apps/public-site/src/content/**`.
This includes uploaded media: `media_folder` is `src/content/uploads` (the build copies it to `/uploads`).
Nothing under `src/pages`, `src/layouts`, `src/components`, `public/`, `astro.config.mjs`, `package.json` or any other app is writable by the CMS.

Decap cannot enforce paths by itself, because it commits with the editor's own GitHub token. Enforcement is layered:

1. **Config.** `public/admin/config.yml` (generated by `pnpm gen:cms-config`) declares only collections whose `folder`/`file` and `media_folder` are under `src/content/`. A test (`tests/unit/cms-drift.test.ts`) fails if any path in the config points elsewhere.
2. **Editorial workflow only.** `publish_mode: editorial_workflow`. Editors never push to `main`; every change is a PR from a `cms/<collection>/<slug>` branch.
3. **CI check `content-only-diff`.** For branches `cms/*`, run `node apps/public-site/scripts/check-content-only.mjs origin/main`. It fails the PR if any changed file is outside `apps/public-site/src/content/`. Make it a required status check (A7 wires it in CI).
4. **Branch protection and CODEOWNERS** (A7 to apply, outside this folder):
   - `main`: PR required, 1 approval, 2 for legal paths, CI green, authors cannot approve their own PR.
   - CODEOWNERS: `/apps/public-site/src/content/legal/` and `/apps/public-site/src/content/pages/*/patients.md` need the legal/privacy reviewer. Everything outside `src/content/` needs a developer reviewer, so a CMS PR touching code is blocked even if check 3 is bypassed.
5. **Roles = GitHub permissions.** Authors: write access without merge rights. Reviewer/Publisher: merge rights. No portal accounts.
6. **Admin hardening.** `/admin/*` is `noindex`, `no-store`, same-origin scripts (Decap is vendored, no CDN), GitHub OAuth proxy is the only external auth host.

Residual risk: a user with repo write access can bypass the CMS and push to a branch. Layers 3 and 4 catch that at PR time.
